# Escopo do MVP — Circuito Terê Verde

## ✅ O que o MVP FAZ (Dentro do Escopo)
- Página inicial com apresentação do projeto e parques em destaque
- Lista de trilhas com informações como dificuldade e duração
- Página com informações sobre biodiversidade, fauna e flora
- Orientações de visitação responsável
- Painel administrativo com visualização de dados
- Layout adaptado para celulares
- Acesso gratuito pela internet

## ❌ O que o MVP NÃO FAZ (Fora do Escopo)
- Sistema de cadastro e login de usuários
- Reserva ou agendamento de visitas
- Mapa interativo com localização em tempo real
- Sistema de comentários e avaliações
- Atualização automática de dados pelo administrador
- Aplicativo para celular (Android ou iPhone)
- Sistema de pagamento ou doações
- Envio de notificações por e-mail ou mensagem

## 📌 Justificativa
Este MVP tem como foco principal **levar informação de qualidade ao visitante**. As funcionalidades mais complexas podem ser adicionadas em versões futuras do projeto.
